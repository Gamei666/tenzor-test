Ansible-playbook для развёртывания тестового окружения на локальной машине, а именно:
1. ВМ с Centos9 на базе последней доступной версии для VirtualBox в официальном репозитории
2. Telegraf внутри ВМ для сбора метрик
3. Docker-контейнер с Graphite на хост-машине для приёма метрик от Telegraf 

Требования:

Дистрибутив семейства RHEL или Debian с поддержкой dnf и apt соответственно.
